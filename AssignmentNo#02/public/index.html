How this works

Nothing fancy — just three steps.

edit

1. Post it

Write what the item looks like and where you last saw it (library, lab, cafeteria, hostel, etc.).

filter_list

2. Check the list

Search by name or place. Filter by Lost / Found if the list gets long.

verified_user

3. Collect it

Bring your UET student card. If it is clearly yours, the department can hand it over and mark it returned.
